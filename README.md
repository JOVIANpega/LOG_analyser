# PEGA Log Analyzer - 專業測試 LOG 快速分析工具

## 📋 專案概述
PEGA Log Analyzer 是一個專門用於分析測試 LOG 檔案的圖形化工具。它能自動辨識多種 LOG 格式（PEGA, IQGPRF 等），並在數秒內提取 PASS/FAIL 數據，生成詳細的 Excel 統計報告。支援多選檔案、資料夾掃描及多種壓縮格式（ZIP/7Z/RAR），大幅提升測試日誌分析效率。

## 🚀 主要功能特色

- **多格式支援**：支援單檔、多選檔案、資料夾掃描及 ZIP/7Z/RAR 壓縮檔。
- **智慧解析**：自動分辨 PASS/FAIL，提取精確數據並過濾系統雜訊。
- **錯誤精準定位**：FAIL 測項自動關聯原始 Log 位置，支援滑鼠懸停即時預覽。
- **Excel 報告生成**：一鍵生成含失敗原因統計、PASS/FAIL 清單的專業報表。
- **現代化介面**：基於 Tkinter 優化，支援字體動態縮放、分割寬度記憶、多樣化高亮。
- **高效率搜尋**：內建全域搜尋 (Ctrl+F)，支援關鍵字持續高亮設定。
