此工具用於分析測試 LOG，並輸出 PASS/FAIL 匯總 Excel（僅針對 CENTIMANIA 格式）。以下只介紹最常用的按鈕與各標籤頁如何操作。

一、左側按鈕區

  • 📁 選擇單一檔案：挑一個 .log 檔進行分析。完成後可在三個標籤頁（PASS / FAIL / 原始LOG）查看結果。
  • 📂 選擇資料夾：一次分析資料夾內所有 .log 檔，並自動在該資料夾下建立 LOG集總整理/，輸出 PASS匯總.xlsx、FAIL匯總.xlsx 與 FAIL匯總_新版.xlsx ⭐。完成時跳出白底提示窗，可一鍵開啟輸出資料夾。
  • 📦 讀取壓縮檔LOG：選擇 ZIP/7Z/RAR 壓縮檔案，自動解壓縮並分析其中的 LOG 檔案。支援多層目錄結構，會自動搜尋所有 .log 檔案。
  • 🗃️ 讀取多個壓縮檔：選擇包含多個壓縮檔的資料夾，會顯示所有壓縮檔清單供您勾選要處理的檔案。支援多層嵌套壓縮檔，可選擇性處理特定壓縮檔。
  • 🗑️ 清除結果：清空 PASS/FAIL/原始LOG 的畫面內容。
  • 🔍 搜尋功能：在搜尋框中輸入關鍵字，支援在 PASS、FAIL、原始LOG 標籤頁中搜尋。使用「下一個」和「上一個」按鈕導覽搜尋結果，或按 Ctrl+F 使用內建搜尋功能。
  • 📖 查看操作說明(HTML)：開啟本頁。

左上「已選擇：檔案/資料夾」會顯示目前的選擇，字體大小跟「內容字體」聯動。

二、PASS 標籤頁（✅ PASS測項）

  • 顯示所有通過的測試步驟清單，欄位：Step Name / 指令 / 回應 / 結果。
  • 內容字體可由左側「介面設定 → 內容字體」加減調整。
  • 若需檢視完整原始內容，切到「📄 原始LOG」。

三、FAIL 標籤頁（❌ FAIL測項）

  • 畫面上下分割：
    • 上方表格：欄位為 Step Name / 指令 / 錯誤回應 / Retry次數 / 錯誤原因。
    • 下方區域：顯示詳細錯誤內容，含紅色標示的 is Fail 文字。
  • 點選上方任一列，會即時更新下方詳細內容。
  • 打開檔案時會自動選取第一筆 FAIL 方便查看。

四、📄 原始LOG 標籤頁

  • 顯示完整原始 LOG 文字。
  • 若有錯誤行，會自動捲動到錯誤處並套用醒目標示。

五、匯出 Excel（僅「選擇資料夾」時自動執行）

  • 輸出路徑：所選資料夾內的 LOG集總整理/。
  • PASS匯總.xlsx：
    • Summary 工作表：
      • 欄位：檔名、PASS項目（超過 25 筆會水平分欄為 PASS項目2、3…）。
      • 相同 PASS 項目集合會合併成一組，檔名欄以換行列出所有對應檔名，包含 SFIS 與測試總秒數。
      • 底部提供「工作表快速連結（點擊跳轉）」；僅此區有超連結與懸停預覽（約 400x500）。
    • 各 LOG 工作表：第 1 行檔名（綠底白字），第 2 行 PASS 項目清單，第 3 行起貼上原始 LOG。
  • FAIL匯總.xlsx：
    • Summary 工作表：欄位 檔名 / FAIL原因，原因取自單檔主錯（例如：IPIO009-0580:Check Battery_tempture is Fail !）。
    • 各 LOG 工作表：第 1 行檔名（紅底白字），第 2 行主要錯誤原因，第 3 行 PASS 項目，第 4 行起為原始 LOG。

六、常見問題

  • 檔名是中文？→ 支援繁體中文檔名。
  • Excel 提示修復？→ 已做文字清理與格式保護；仍發生時，請先更新 Office 版本，並回報樣本 LOG。
  • 看不到預覽視窗？→ 只有 Summary 底部的「工作表快速連結」具備懸停預覽。

八、V1.9.0 新功能

🗃️ 多選壓縮檔功能

  • 批次處理：選擇包含多個壓縮檔的資料夾
  • 選擇性解壓：顯示所有壓縮檔清單，可勾選要處理的檔案
  • 多層嵌套：支援壓縮檔內還有壓縮檔的複雜結構
  • 進度顯示：顯示解壓縮和分析進度百分比
  • 可取消操作：處理過程中可隨時取消

🔍 搜尋功能

  • 跨標籤頁搜尋：支援在 PASS、FAIL、原始LOG 標籤頁中搜尋關鍵字
  • 內建 Ctrl+F：使用 Tkinter 內建搜尋功能，支援上下搜尋
  • 搜尋高亮：找到的匹配文字以黃底黑字高亮顯示
  • 循環搜尋：搜尋到末尾時自動從頭開始

💡 Tooltip 提示功能

  • 全面覆蓋：所有按鈕和輸入欄位都有詳細說明
  • 智能顯示：滑鼠懸停時顯示，離開時隱藏
  • 多行支援：支援多行文字和自動換行
  • 位置追蹤：滑鼠移動時 Tooltip 跟隨顯示

🔒 加密驗證功能

  • 檔案驗證：啟動時檢查 SIGN.txt 加密檔案
  • 內容驗證：驗證檔案內容是否包含授權字串
  • 安全啟動：只有通過驗證才能正常使用程式
  • 錯誤提示：驗證失敗時顯示明確的錯誤訊息

八、V1.9.0 新功能 ⭐

📊 新版Excel報告格式 (FAIL匯總_新版.xlsx)

V1.9.0 引入全新的結構化Excel報告格式，讓錯誤分析更直觀、更高效！

🎯 Dashboard 工作表

提供一目了然的錯誤總覽，包含以下欄位：

  • 狀態：🔴 視覺標識
  • ISN：序列號 (自動從檔名提取，如 WE253600014)
  • Station：測試站點 (自動提取，如 "4cam stitching1")
  • 錯誤類型：智能分類的主要錯誤 (帶顏色標識)
  • 錯誤詳情：簡短的錯誤描述
  • 發生時間：測試時間戳
  • Retry次數：重試次數統計
  • 查看詳細：超鏈接直接跳轉到原始LOG工作表

📋 FAIL_LIST 工作表

詳細的失敗項目列表，包含：

  • ISN：序列號
  • Station：測試站點
  • 測試項目：失敗的具體測試步驟
  • 錯誤類型：錯誤分類
  • 錯誤原因：詳細的錯誤信息
  • 執行指令：失敗時執行的指令

🎨 智能錯誤分類系統

自動識別並分類6種常見錯誤類型，使用顏色編碼：

  • 🔴 系統崩溃：Segmentation Fault, core dumped
  • 🟠 數值不匹配：doesn't match
  • 🟡 超時錯誤：timeout
  • 🌸 執行失敗：executes fail
  • 🌺 參數錯誤：Wrong, exception
  • ⚪ 其他錯誤：FAIL, ERROR

🔍 4級優先級錯誤提取

使用智能算法提取最關鍵的錯誤信息：

  1. 優先級1：最後一次出現的 "doesn't match"
  2. 優先級2：最後一次出現的 "is Fail"
  3. 優先級3：最後一次出現的 "FAIL"
  4. 優先級4：最後一次出現的 "ERROR"

📁 雙版本輸出

重要：V1.9.0 同時生成兩個版本的FAIL報告：
• FAIL匯總.xlsx - 傳統格式（保留向後兼容）
• FAIL匯總_新版.xlsx - 新格式（Dashboard + FAIL_LIST）⭐

🔧 代碼優化

  • 模組化重構：將大型文件拆分為多個小模組，提高可維護性
  • UI模組：enhanced_treeview, enhanced_text, fail_details_panel
  • Excel模組：excel_utils, excel_fail_list_builder
  • 代碼質量：所有模組均符合1000行以內的最佳實踐
