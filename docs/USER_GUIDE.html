此工具用於分析測試 LOG，並輸出 PASS/FAIL 匯總 Excel（僅針對 CENTIMANIA 格式）。以下只介紹最常用的按鈕與各標籤頁如何操作。

一、左側按鈕區

  • 📂 選擇 LOG 來源 (檔案/資料夾)：整合型智能按鈕。點擊後可選擇：
    • 📄 選擇檔案：挑選單個或多個 .log、壓縮檔 (zip/7z/rar)。
    • 📁 選擇資料夾：批次分析資料夾內所有檔案。
  • 📊 CSV檔案整理：選擇目錄自動搜尋 CSV 檔案並整理。
  • 🗑️ 清除結果：清空所有顯示結果與暫存狀態。
  • 🔍 搜尋功能：輸入關鍵字後可跨標籤頁搜尋，找到的文字會以黃底高亮顯示。
  • 📖 查看操作說明(HTML)：點擊即可開啟本頁面進行快速查閱。

移除原有的多個繁雜按鈕，整合為單一入口，操作更直覺。

二、PASS 標籤頁（✅ PASS測項）

  • 顯示所有通過的測試步驟清單，欄位：Step Name / 指令 / 回應 / 結果。
  • 內容字體可由左側「介面設定 → 內容字體」加減調整。
  • 若需檢視完整原始內容，切到「📄 原始LOG」。

三、FAIL 標籤頁（❌ FAIL測項）

  • 畫面上下分割：
    • 上方表格：顯示失敗的測項。
    • 下方區域：顯示詳細錯誤內容。採用 Bottom-up 智能分析，只顯示最關鍵的錯誤原因（如 doesn't match）。
  • 色彩標示：主要錯誤會以紅色文字搭配粉紅背景顯示，與 Excel 報表完全一致。

四、📄 原始LOG 標籤頁

  • 錯誤區塊置頂預覽 (New)：打開原始 LOG 時，系統會自動將錯誤發生的指令區塊（從下指令到錯誤結束）直接複製顯示在最頂端，無需捲動即可看到原因。
  • 視覺簡化：移除斑馬紋背景，採用更清晰的白底。
  • 自動聚焦：自動捲動到第一個錯誤行。
  • 滑鼠懸停高亮：滑鼠滑過的行會即時加亮。

新版本移除舊有的摺疊與斑馬紋功能，改以色彩標註與置頂預覽替代，提升可讀性。

五、匯出 Excel（僅「選擇資料夾」時自動執行）

  • 輸出路徑：所選資料夾內的 LOG集總整理/。
  • PASS匯總.xlsx： Summary 工作表與詳細 LOG。
  • FAIL匯總.xlsx：
    • FAIL_LIST 工作表：
      • 列出所有失敗項目與原因。
      • ISN 超連結 (New)：點擊 ISN 序號，可直接跳轉到該 LOG 工作表中錯誤發生的確切行數。
      • 圓餅圖 (已移除以簡化報表)。
    • 風格統一：所有錯誤行與區塊均使用紅色文字與粉紅背景，與 GUI 保持一致。

六、常見問題

  • 檔名是中文？→ 支援繁體中文檔名。
  • Excel 提示修復？→ 已做文字清理與格式保護；仍發生時，請先更新 Office 版本，並回報樣本 LOG。
  • 看不到預覽視窗？→ 只有 Summary 底部的「工作表快速連結」具備懸停預覽。

七、新功能說明 (V1.6.6)

  • 🔍 彈出視窗搜尋功能：搜尋按鈕已更新為橘色背景，提升視覺辨識度
  • 📱 智能視窗定位：改善多視窗重疊問題，自動避免視窗重疊
  • 🎨 字體大小調整：支援介面字體大小動態調整，包含按鈕和彈出視窗
  • ⚡ 效能優化：改善視窗開啟速度和響應性

新版本已解決視窗重疊問題，並提供更好的使用者體驗！

九、V2.0.0 重大更新 ⭐ (2025-12-24)

🖱️ 自定義高亮關鍵字介面

  • + 高亮按鈕：在 FAIL 詳細資訊視窗底部搜尋框輸入文字後點擊，可將該字串存入持久記憶清單。
  • 持久記憶：設定會自動保存在 settings.json，下次開啟程式時依然有效。
  • 整行標記：出現關鍵字的「整行」會自動以黃底黑字加粗顯示，極速定位 SPEC_FAIL 等特定問題。
  • 預設內建：系統已預設包含 SPEC_FAIL 與 spec_issue:。

📈 Excel 視覺美化與增強

  • 標籤頁上色：Excel 報表中，「統計摘要」分頁標記為深藍色，「FAIL_LIST」標記為鮮紅色。
  • 圓餅圖放大：將圓餅圖的數據標籤字體提升至 **14pt**，閱讀更清晰。
  • 總測試時間：自動從 Log 結尾提取並顯示 **All phase Total Test Time**。

🔬 進階 Log 高亮邏輯 (Excel)

  • 區塊級高亮：若一個指令步區塊發生錯誤，整段文字將以**紅色加粗**顯示。
  • 精確錯誤背景：發生錯誤的那一行會額外增加**黃色背景**，幫助您精確鎖定失敗點。
  • 富文本支援：一般行內的錯誤關鍵字（如 fail, nack）會單獨以紅色高亮顯示。

十、V2.1.0 視覺簡化與體驗升級 ⭐ (2025-12-26)

🎨 視覺降噪 (Visual Simplification)

  • 移除斑馬紋：全面移除 GUI 與 Excel 中的藍紫相間斑馬紋，回歸乾淨白底，減少視覺疲勞。
  • 精確錯誤高亮：
    • Doesn't match 區塊：從下指令到錯誤結束的整段文字，統一使用粉紅背景 + 紅色粗體標示。
    • 單行錯誤：FAIL/ERROR/NACK 等關鍵字行單獨紅底高亮。

🚀 操作體驗升級

  • 錯誤置頂預覽：在 GUI「原始 LOG」分頁，錯誤發生的過程直接「置頂顯示」，一眼看到原因。
  • 单一智能按鈕：左側按鈕整併為「📂 選擇 LOG 來源」，支援所有類型檔案與資料夾。
  • GUI/Excel 邏輯同步：確保 GUI 看到的錯誤原因與 Excel 報表完全一致（嚴格遵循 Bottom-up 優先級）。
  • Excel 超連結優化：FAIL_LIST 的 ISN 序號現在是超連結，點擊直接跳轉到錯誤行。
