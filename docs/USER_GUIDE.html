此工具用於分析測試 LOG，並輸出 PASS/FAIL 匯總 Excel（僅針對 CENTIMANIA 格式）。以下只介紹最常用的按鈕與各標籤頁如何操作。

一、左側按鈕區

  • 📁 選擇檔案 (Log/壓縮檔)：挑一個或多個 .log 或壓縮檔進行分析。支援一次載入多份 Log。
  • 📂 選擇資料夾 (自動識別)：一次分析資料夾內所有檔案。
  • 🗑️ 清除結果：清空所有顯示結果與暫存狀態。
  • 🔍 搜尋功能：輸入關鍵字後可跨標籤頁搜尋，找到的文字會以黃底高亮顯示。
  • ⚡ 執行中動畫：當分析檔案開始時，左側 Owl Logo 與標題「PEGA LOG ANALYZER」會呈現顯眼的綠/黃色彩閃爍，代表正在運算中。
  • 📖 查看操作說明(HTML)：點擊即可開啟本頁面進行快速查閱。

移除原有的狀態指示燈，改以標題閃爍作為主要的處理中視覺回饋。

二、PASS 標籤頁（✅ PASS測項）

  • 顯示所有通過的測試步驟清單，欄位：Step Name / 指令 / 回應 / 結果。
  • 內容字體可由左側「介面設定 → 內容字體」加減調整。
  • 若需檢視完整原始內容，切到「📄 原始LOG」。

三、FAIL 標籤頁（❌ FAIL測項）

  • 畫面上下分割：
    • 上方表格：欄位為 Step Name / 指令 / 錯誤回應 / Retry次數 / 錯誤原因。
    • 下方區域：顯示詳細錯誤內容，含紅色標示的 is Fail 文字。
  • 點選上方任一列，會即時更新下方詳細內容。
  • 打開檔案時會自動選取第一筆 FAIL 方便查看。

四、📄 原始LOG 標籤頁

  • 顯示完整原始 LOG 文字，採用高效率線性顯式。
  • 自動聚焦：切換到此標籤頁時，程式會自動尋找第一個錯誤行（如 FAIL 或 Exception）並捲動到該位置。
  • 滑鼠懸停高亮：滑鼠滑過的行會即時加亮（優化後的局部更新技術，即使萬行 Log 也不卡頓）。
  • 醒目標示：FAIL/ERROR 區域會以淺紅色背景標註，方便一眼看出故障範圍。

考慮到穩定性，新版本已移除舊有的摺疊功能，改以色彩標註與快速對焦替代。

五、匯出 Excel（僅「選擇資料夾」時自動執行）

  • 輸出路徑：所選資料夾內的 LOG集總整理/。
  • PASS匯總.xlsx：
    • Summary 工作表：
      • 精簡化欄位：檔名 / 腳本檔案 / SFIS / 測試總時間。
      • 自動美化：針對長路徑自動調整欄寬。檔名欄支援超連結點擊跳轉，並具備懸停預覽內容功能。
    • 各 LOG 工作表：第 1 行檔名（綠底白字），第 2 行 PASS 項目清單，第 3 行起貼上原始 LOG。
  • FAIL匯總.xlsx：
    • FAIL_LIST 工作表 (優化) ⭐：
      • 依 FAIL Item 自動記數與排名。系統會自動移除項目名稱中冗餘的 "FAIL" 字眼，使報表更易讀。
      • 提供錯誤排名統計表格與橫條圖 (Bar Chart)，快速定位高頻 Fail 項目。
    • Summary 工作表：提供所有檔案的 FAIL 原因總覽。

六、常見問題

  • 檔名是中文？→ 支援繁體中文檔名。
  • Excel 提示修復？→ 已做文字清理與格式保護；仍發生時，請先更新 Office 版本，並回報樣本 LOG。
  • 看不到預覽視窗？→ 只有 Summary 底部的「工作表快速連結」具備懸停預覽。

七、新功能說明 (V1.6.6)

  • 🔍 彈出視窗搜尋功能：搜尋按鈕已更新為橘色背景，提升視覺辨識度
  • 📱 智能視窗定位：改善多視窗重疊問題，自動避免視窗重疊
  • 🎨 字體大小調整：支援介面字體大小動態調整，包含按鈕和彈出視窗
  • ⚡ 效能優化：改善視窗開啟速度和響應性

新版本已解決視窗重疊問題，並提供更好的使用者體驗！

九、V2.0.0 重大更新 ⭐ (2025-12-24)

🖱️ 自定義高亮關鍵字介面

  • + 高亮按鈕：在 FAIL 詳細資訊視窗底部搜尋框輸入文字後點擊，可將該字串存入持久記憶清單。
  • 持久記憶：設定會自動保存在 settings.json，下次開啟程式時依然有效。
  • 整行標記：出現關鍵字的「整行」會自動以黃底黑字加粗顯示，極速定位 SPEC_FAIL 等特定問題。
  • 預設內建：系統已預設包含 SPEC_FAIL 與 spec_issue:。

📈 Excel 視覺美化與增強

  • 標籤頁上色：Excel 報表中，「統計摘要」分頁標記為深藍色，「FAIL_LIST」標記為鮮紅色。
  • 圓餅圖放大：將圓餅圖的數據標籤字體提升至 **14pt**，閱讀更清晰。
  • 總測試時間：自動從 Log 結尾提取並顯示 **All phase Total Test Time**。

🔬 進階 Log 高亮邏輯 (Excel)

  • 區塊級高亮：若一個指令步區塊發生錯誤，整段文字將以**紅色加粗**顯示。
  • 精確錯誤背景：發生錯誤的那一行會額外增加**黃色背景**，幫助您精確鎖定失敗點。
  • 富文本支援：一般行內的錯誤關鍵字（如 fail, nack）會單獨以紅色高亮顯示。
