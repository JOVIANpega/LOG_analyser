此工具用於分析測試 LOG，並輸出 PASS/FAIL 匯總 Excel（僅針對 CENTIMANIA 格式）。以下只介紹最常用的按鈕與各標籤頁如何操作。

一、左側按鈕區

  • 📁 選擇檔案 (Log/壓縮檔)：挑一個或多個 .log 或壓縮檔進行分析。支援一次載入多份 Log。
  • 📂 選擇資料夾 (自動識別)：一次分析資料夾內所有檔案，並自動在該資料夾下建立 LOG集總整理/。
  • 🗑️ 清除結果：清空所有顯示結果與暫存狀態。
  • 🔍 搜尋功能：輸入關鍵字後可跨標籤頁搜尋，找到的文字會以黃底高亮顯示。
  • ⚡ 執行中動畫：當分析檔案開始時，左上方的標題「PEGA LOG ANALYZER」會呈現閃爍效果，直到處理完成為止。
  • 📖 查看操作說明(HTML)：點擊即可開啟本頁面進行快速查閱。

左上標題與介面字體大小可於「設定」標籤頁中即時調整並看到效果。

二、PASS 標籤頁（✅ PASS測項）

  • 顯示所有通過的測試步驟清單，欄位：Step Name / 指令 / 回應 / 結果。
  • 內容字體可由左側「介面設定 → 內容字體」加減調整。
  • 若需檢視完整原始內容，切到「📄 原始LOG」。

三、FAIL 標籤頁（❌ FAIL測項）

  • 畫面上下分割：
    • 上方表格：欄位為 Step Name / 指令 / 錯誤回應 / Retry次數 / 錯誤原因。
    • 下方區域：顯示詳細錯誤內容，含紅色標示的 is Fail 文字。
  • 點選上方任一列，會即時更新下方詳細內容。
  • 打開檔案時會自動選取第一筆 FAIL 方便查看。

四、📄 原始LOG 標籤頁

  • 顯示完整原始 LOG 文字。
  • 若有錯誤行，會自動捲動到錯誤處並套用醒目標示。

五、匯出 Excel（僅「選擇資料夾」時自動執行）

  • 輸出路徑：所選資料夾內的 LOG集總整理/。
  • PASS匯總.xlsx：
    • Summary 工作表：
      • 精簡化欄位：檔名 / 腳本檔案 / SFIS / 測試總時間。
      • 自動美化：針對長路徑自動調整欄寬。檔名欄支援超連結點擊跳轉，並具備懸停預覽內容功能。
    • 各 LOG 工作表：第 1 行檔名（綠底白字），第 2 行 PASS 項目清單，第 3 行起貼上原始 LOG。
  • FAIL匯總.xlsx：
    • FAIL_LIST 工作表 (優化) ⭐：
      • 依 FAIL Item 自動記數與排名。系統會自動移除項目名稱中冗餘的 "FAIL" 字眼，使報表更易讀。
      • 提供錯誤排名統計表格與橫條圖 (Bar Chart)，快速定位高頻 Fail 項目。
    • Summary 工作表：提供所有檔案的 FAIL 原因總覽。

六、常見問題

  • 檔名是中文？→ 支援繁體中文檔名。
  • Excel 提示修復？→ 已做文字清理與格式保護；仍發生時，請先更新 Office 版本，並回報樣本 LOG。
  • 看不到預覽視窗？→ 只有 Summary 底部的「工作表快速連結」具備懸停預覽。

七、新功能說明 (V1.6.6)

  • 🔍 彈出視窗搜尋功能：搜尋按鈕已更新為橘色背景，提升視覺辨識度
  • 📱 智能視窗定位：改善多視窗重疊問題，自動避免視窗重疊
  • 🎨 字體大小調整：支援介面字體大小動態調整，包含按鈕和彈出視窗
  • ⚡ 效能優化：改善視窗開啟速度和響應性

新版本已解決視窗重疊問題，並提供更好的使用者體驗！

八、V1.9.0 新功能 ⭐

📊 FAIL 匯總報告升級

1. 圓餅圖統計 (Pie Chart)

在 FAIL匯總.xlsx 的 FAIL_LIST 工作表中，新增了直觀的圓餅圖：

  • 位置：位於錯誤統計表格右側 (H欄)
  • 內容：顯示各類錯誤的佔比與數量
  • 用途：快速識別主要失效原因 (Top Failure Modes)

2. 統計表格優化

  • 自動統計各類錯誤數量
  • 按錯誤發生頻率降序排列
  • 顯示錯誤百分比

🗃️ 壓縮檔支援增強

  • 多檔選擇：支援一次選擇多個壓縮檔 (ZIP/7Z/RAR)
  • 智能路徑：若是暫存目錄，Excel 自動輸出到原始路徑或桌面，避免檔案遺失
  • 進度提示：更準確的解壓縮與分析進度顯示

💡 介面體驗優化

  • 閃爍提示：分析進行時，Owl Logo 與標題會呈現 綠/黃 交替閃爍，狀態更明顯
  • 完成提示：分析結束後彈出對話框，可直接勾選開啟 Excel 或資料夾
