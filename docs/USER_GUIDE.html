PEGA Log Analyzer

日誌分析工具 - 使用說明

🛠️ 工具簡介與特色

PEGA Log Analyzer 用於分析 Pega 測試日誌，整合了錯誤提取、規格比對與報表產出功能。其設計重點在於簡化日常排錯流程與數據整理工作。

  • 日誌分析：自動辨識測試階段 (Phase) 並提取失敗原因。
  • 數值判定：自動比對實測值與標準值 (Criteria)，並將異常項反白顯示。
  • 影像連結：分析完成後可直接搜尋對應 ISN 的測試紀錄圖檔。
  • 數據整理：批次導出 Excel 分析報表與 CSV 生產數據規格化。
【圖 0】介面概覽：整合檔案管理、搜尋、導覽與標籤化顯示

📂 1. 載入日誌 (單檔、壓縮包、資料夾)

點擊左側面板的 「選擇 LOG 來源」 按鈕即可載入資料。目前支援以下載入方式：

  • 選擇檔案：選取 .log 檔案（支援 Shift 多選）。
  • 讀取壓縮檔：直接選取 ZIP 或 7z 檔案，程式會自動讀取內容。
  • 讀取資料夾：選取目錄後，程式會自動過濾並分析其中的日誌檔案。
【圖 1】支援多種來源載入

📊 2. 規格比對與錯誤跳轉 (單檔案分析)

匯入單一 Log 後，程式會自動比對規格並提取錯誤點。

  • 規格比對 (Criteria)：
    • 數值比對：自動辨識 Value = 5.1 (4.5, 5.5) 等格式。
    • 狀態標記：符合規範顯示綠色，不符合則標記為紅底白字。
  • 錯誤跳轉 (預覽)：
    • 錯誤提取：在視窗上方顯示 Log 中的關鍵錯誤行。
    • 快速導航：點擊預覽區域的紅底文字，可自動跳轉至對應行號。

🔍 3. 日誌搜尋與導覽

提供日誌全文搜尋與快速捲動功能。

  • 搜尋 (Ctrl+F)：開啟搜尋框，支援歷史關鍵字。
  • 歷史紀錄：搜尋列會紀錄最近 5 筆關鍵字，方便重複檢索。
  • 快速捲動：使用 TOP/END 按鈕或鍵盤 PGUP/PGDN 鍵。
【圖 4】搜尋面板與導覽按鈕

📸 4. 圖片檢索功能 (ISN)

根據 ISN 快速開啟測試影像。

  • 自動帶入 ISN：分析完 Log 後，會自動提取 ISN 並填入搜圖欄位。
  • 選取資料夾：可手動指定掃描目錄（不限於預設路徑）。
  • 批次功能：支援一次開啟所有影像，或將圖檔複製至指定目錄。
【圖 5】圖片檢索：依照鏡頭位置分組顯示搜尋到的影像

📊 5. 匯出 Excel 統計報告

將分析結果匯出為 Excel 報表。

  • 分站彙整：自動根據檔案名稱識別測試站別。
  • 統計摘要：自動計算 PASS/FAIL 數量與比例。
  • 內文跳轉：在 Excel 中可直接跳轉至原始日誌行號。

🏢 7. 支援格式與 ZIP/7z

支援多種日誌來源與壓縮檔格式。

  • 壓縮檔讀取：可直接讀取 ZIP 或 7z 檔案，無需手動解壓。
  • 混合讀取：可同時處理檔案、壓縮檔與資料夾。

⚙️ 9. 自定義設定詳解

透過設定分頁，您可以調整分析引擎的邏輯、圖片檢索路徑以及介面顯示細節。

【圖 11】主設定區域：管理判定邏輯與視覺縮放

9.1 FAIL 判定邏輯 (重要)

此設定決定了程式如何定義一個測試步驟為「失敗」：

  • 自定義關鍵字：在此處輸入您專案中代表錯誤的詞彙（例如 NACK, Bad_Sum, timeout），並以逗號分隔。
  • 運作方式：分析引擎在掃描 Log 時，若某個 Phase 區塊內包含這些字串，該 Phase 將立即顯示為紅色的 FAIL。
  • 置頂預覽：所有匹配到的關鍵字行，都會被提取至 Log 視窗最上方的快速預覽框中。

9.2 視覺顯示與字體縮放

針對不同解析度的顯示器（例如 4K 螢幕）進行優化：

  • 介面文字大小：調整按鈕、標籤與選單的字體。
  • 內容字體大小：專門調整 Log 內文的顯示大小，建議設為稍微大一點以便長時間閱讀。
  • 介面主題：提供多種內建配色（如 Superhero 深色、Litera 淺色等），切換後會立即更改整體 UI。
【圖 12】圖片檢索進階設定

9.3 圖片檢索自動化設定

讓程式能精準定位圖片伺服器或本地路徑：

  • 搜尋根路徑：通常設為伺服器的掛載槽或圖片主目錄（如 Z:\ 或 D:\IMAGES）。
  • 目標資料夾關鍵字：程式會自動在根路徑下尋找包含此名稱的資料夾（預設為 STATION_RECORD）。
  • ISN 識別前綴：例如設定為 WE，分析 Log 後若提取到 WE123456，系統會自動使用此號碼去搜尋圖片。

9.4 其他功能開關

  • 自動開始分析：開啟後，只要選取檔案或資料夾，程式會略過手動確認直接啟動解析流程。
  • 忽略未找到時間的 LOG：勾選此項可自動過濾掉不具備測試紀錄（空檔或損毀檔）的無效日誌。
  • 懸停預覽彈窗：在分析結果清單中，將滑鼠移到測項上會自動跳出詳細的參數與回傳值（預設建議關閉以保持清爽）。
  • LOG 懸停顏色：定義在原始日誌中滑鼠滑過行號時的提示底色（黃、藍、綠、紫、灰）。

* 每次修改完設定後，請務必點擊底部的「儲存所有設定」按鈕，變更才會寫入 settings.json 並在下次啟動時生效。
