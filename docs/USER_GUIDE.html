PEGA Log Analyzer V2.0.0

專業測試 Log 快速分析工具 - 操作說明手冊

🌟 核心功能覽

🚀 多格式支援 支援單一 .log、多選檔案、.zip、.7z 壓縮檔及整個資料夾。
📊 嚴格數據提取 自動捕捉 xxx = OOO (OOO) 規律的比對數據，過濾無關雜訊。
🔍 錯誤精準定位 FAIL 項目自動關聯原始 Log 位置，並提供關鍵區塊預覽。
📈 Excel 報表生成 一鍵生成統計報表，含失敗原因分類圖表與詳細 PASS/FAIL 清單。

📖 如何使用（三步驟）

選擇檔案：使用左側面板的「選擇檔案」、「選擇資料夾」或「選擇壓縮檔」。您可以一次選取多個檔案進行批次分析。
查看結果：
  • ✅ PASS測項：查看成功的測試步驟及其精確的比對數值。
  • ❌ FAIL測項：查看失敗的錯誤回應、FAIL原因及重試次數。點選項目可直接在原始 Log 中跳轉到錯誤位置。
  • 📄 原始LOG：即時查看完整的日誌內容，支援關鍵字高亮快搜。
產出報表：分析完成後，系統會詢問是否開啟產出的 Excel 文件。這份文件包含了所有測試項目的彙總，非常適合做為測試報告。

⚙️ 進階操作技巧

  • 高亮關鍵字：在原始 LOG 頁面使用搜尋功能後，點選「+高亮」可將該字串存入設定，往後打開任何 LOG 都會自動標色。
  • 縮放字體：使用滑鼠滾輪或設定頁面調整文字大小，適應不同的顯示器解析度。
  • 過濾雜訊：系統已內建自動過濾 Ping、ICMP 等系統雜訊，讓您專注於測試參數。
